# Anixart Desktop — обновления

Готовые сборки Windows x64 и macOS 14.4+ (Intel и Apple Silicon).

Установочные файлы публикуются в Releases. Исходный код хранится отдельно.
Клиент проверяет цифровую подпись описания обновления и SHA-256 файла перед установкой.

Первая версия с обновлятором — 4.6.0 — устанавливается вручную. Дальше обновления доступны в настройках приложения.
